# 存档系统（CCST 快照链）与指定位置存档生成 ★ 附加工作

本文档是补丁主线之外的附加工作记录：AdvHD（MoeNovel 系）引擎存档格式的逆向结论
与指定位置存档生成工具的用法，独立于补丁管线，不参与补丁构建流程。
逆向过程（x32dbg 断点抓现场 + IDA 静态链 + 数据驱动验证）的完整记录见
`tmp/savegen/EXPERIMENTS.md`（临时目录，不入库），本文档只保留结论。

## 文件布局

存档目录在 `%USERPROFILE%\Saved Games\MoeNovel\<英文标题>\`。主文件
`Save%03d.<标题>Save-MoeNovel` 是一串首尾相接的 CCST 块，无文件头；第 0 块为当前状态，
物理 1..N-1 为按时间旧→新排列的历史环形缓冲（上限 251 块，环满覆写最旧）。
savepoint 截图是独立的同名 PNG（116×65，可缺失）；槽位由引擎枚举磁盘文件获得，
无索引文件。

伴随文件：`Save000`（全局小状态快照）、`Save000Favorite`（240 槽收藏位图，全 FF 为空）、
`Save000GS`、`Resume.*`（最近读档）、`MessageFlag.dat`（逐脚本既読位图）。

## 块内布局（小端，逆向 + 数据验证）

- `+0x00`：魔数 `CCST`。常量不在 exe 内——由 `GameInfo.lua` 的 `getAppInfo` 第 4 字段
  （4 字符串）提供，引擎初始化器（0x417760）启动时读入全局 `dword_594E68`。
- `+0x04`：tick（u32）。单位未确证；**跨游戏进程会归零**，同一存档的历史链里可含
  多次进程重启造成的回落，不能当全局时间轴。
- `+0x08`：16 字节零（两个长度为 0 的字符串位：注释/章节名）。
- `+0x14`：对白文本长（UTF-16 码元数）。
- `+0x18`：对白文本（UTF-16LE，经 lng 与 NameTable 渲染后的最终显示文本）。
- 其后：引擎运行时对象图。无统一结构，各运行时对象虚序列化自己——图层参数（f32 坐标/缩放）、
  E-mote 状态、消息历史（每条 5 个字符串字段）、变量表、旗标位图、场景资源名等；
  脚本名（如 `CCB1006_EN`）出现在消息历史条目内，不是独立字段。

块内所有字符串均为 `[u32 长度][UTF-16LE 内容]`。字符串常量如 `@ANIMATION_KEY` 在 exe
中不存在明文，为运行时拼接。

## PC 字段（位置恢复）★

- **位置**：对象图起点（`0x18 + 对白文本长×2`）+ `0x410` 处的 u32。
- **语义**：ws2 解析游标 `<< 8`（低字节恒 0）。游标是引擎在 ws2 流中的原始解析位置，
  保存时停在「当前消息显示完、下一条显示指令已预解析」处；读档后从游标继续顺序解析，
  停在并显示后续消息。
- **写入规则**：跳到目标消息 M（`0x14`/`0x2e` DisplayMessage 指令，偏移 `off`）→
  写 `(off + 3) << 8`（3 = opcode 1 字节 + id 2 字节；引擎恢复时读完指令头即显示 M）。
- **验证**：全部 46 个真实存档（跨全部脚本/场景）低字节=0 且游标落在对应脚本范围内，
  0 例外；`Save090`（种子 Save084 + 游标改到 CCB1006 首条消息）实机验证落在场景开头、
  无卡顿、后续游玩正常。
- 图起点到 PC 字段之间（0x410 字节）为引擎固定布局，不随场景变化；场景相关的对象
  （图层、资源表等）在 PC 字段之后。

## 加载失败的表现

存档数据不完整或被改坏时，解析器从内部字段读出垃圾计数 → `std::vector` 扩容巨额分配 →
`std::bad_alloc`（未捕获 → CRT "Runtime Error" 固定文案弹窗，或直接闪退，
EventLog 异常码 0xE06D7363）；垃圾值可分配但解析不收敛则表现为卡死。
截断/重排实验中同一文件结局不稳定，源于解析越界读到堆内存（每次运行内容不同）。
两种失败路径都经过 `KERNELBASE!RaiseException`。

读档路径上会调用 LNG 文本池加载（0x402930），其 `.lng` XOR 键同样来自
`GameInfo.lua`（`getHostInfo` 的数字字段 → `byte_594E74`，值 0x2C）。

## 生成工具

`tool/make_save.py`（项目根执行）：

    # 列出某脚本全部可跳消息（序号 / id / ws2 偏移 / 中文文本）
    python -m tool.make_save --list CCB1006

    # 以槽位 084 的存档为种子，跳到 CCB1006 第 0 条消息，写入槽位 090
    python -m tool.make_save --seed 084 --slot 090 --script CCB1006 --index 0

- 目标消息按「显示指令在 ws2 流中的出现顺序」编号，文本为 lng 渲染后的中文。
- 内置防呆：种子第 0 块的脚本一致性检查、块结构校验；写盘后回读校验 PC 字段与块数。
- 幂等：同参数重复运行产出相同文件。
- 限制：目标脚本必须与种子存档当前脚本一致（引擎「当前脚本」标识的存储点尚未逆向，
  跨脚本移植待解）。跨脚本跳转的权宜做法：先用引擎在目标脚本里存一份档作种子。
