# 验收标准

## 功能验收

### 调用链完整性

- [ ] 所有跳转目标脚本存在
- [ ] 调用链连续且可达
- [ ] 无悬空引用
- [ ] 原版 H 场景正确插入 Steam 版调用链

### 脚本存在性

- [ ] 所有新增的 `*_h.ws2` 脚本存在于 Rio.arc 中
- [ ] 所有改写后的 Steam 脚本跳转目标正确
- [ ] 脚本数量符合预期（Steam 364 + 新增 H 场景）

### 资源完整性

#### PNA/PNG 资源

- [x] 所有原版 H 场景 CG 存在（36 个 CN_EVCC* + 1 个 CN_SGCC0020）
- [x] 所有原版立绘存在
- [x] Chip2.arc 仅含 `EVCC*`/`CN_EVCC*` 前缀成员，不含其他前缀
- [x] Graphic.arc 不含 `CN_EVCC*` 前缀成员（允许含 `CN_SGCC0020.PNG`，与既有 SGCC 系统图族命名惯例一致）
- [x] 无同名冲突（CN_ 前缀零冲突，无需改名隔离）

#### 背景与特效资源

- [ ] 所有 H 场景引用的背景 PNG 存在
- [ ] 所有特效遮罩存在（如需）
- [ ] 从原版补入的资源完整

#### 语音资源

- [ ] 所有 H 场景语音存在于 Voice.arc 中
- [ ] 语音文件格式正确（OGG）
- [ ] 语音文件大小合理

### 汉化完整性

#### 文本汉化

- [ ] 所有剧情文本的 lng 文件存在
- [ ] lng 文件数量符合预期（364 个，对应 364 个 ws2）
- [ ] lng 文件格式正确（rot6 混淆）

#### 字体支持

- [ ] Fonts.arc 包含支持汉字的字体文件
- [ ] 字体文件大小符合预期（约 18.5 MB × 2）

#### 系统界面（可选）

- [ ] Script.arc 存在（如实施）
- [ ] Lua 脚本完整（14 个文件）
- [ ] SysGraphic.arc 包含汉化图片（如实施）

### 冗余检测

- [ ] 所有 ORG_* 资源被至少 1 个 `*_h.ws2` 脚本引用
- [ ] 无重复脚本（无同名裸名版本）
- [ ] 无未使用的资源

## 质量标准

### Arc 文件规范化

- [ ] 所有 Arc 文件通过 `arcbuild.verify()` 验证
- [ ] 无 null padding（已规范化）
- [ ] 哈希稳定（多次读写产生相同 SHA256）

### 配对正确性

- [ ] `*_h.ws2` ↔ `ORG_*` 资源
- [ ] `*_en.ws2` ↔ Steam 裸名资源
- [ ] 资源引用与槽位匹配（st* 槽 ↔ 立绘，ev 槽 ↔ 事件 CG）

### 编码正确性

- [ ] 资源名使用 Shift-JIS 编码
- [ ] lng 文件中文本编码正确
- [ ] 无编码错误或乱码

### SHA256 校验

- [ ] 生成 SHA256SUMS 校验文件
- [ ] 所有关键文件的哈希正确
- [ ] 安装器校验通过

## 测试标准

### 功能测试

1. **调用链测试**
   - [ ] 从主菜单进入每条角色线
   - [ ] 确认能正常触发 H 场景
   - [ ] 确认 H 场景结束后能正常续接后续剧情
   - [ ] 测试多分支场景的跳转

2. **资源显示测试**
   - [ ] H 场景 CG 正常显示（无崩溃、无黑屏）
   - [ ] 立绘正常显示
   - [ ] 背景正常载入（无卡死）
   - [ ] 特效遮罩正常（或容忍缺失）

3. **语音播放测试**
   - [ ] H 场景语音正常播放
   - [ ] 语音与台词同步
   - [ ] 语音质量正常

4. **文本显示测试**
   - [ ] 剧情文本显示为简体中文
   - [ ] 角色名称正确显示
   - [ ] 无乱码或编码错误
   - [ ] 文本与场景对应正确

5. **字体显示测试**
   - [ ] 中文字符正常显示
   - [ ] 字体大小适配界面
   - [ ] 无字符缺失或显示为方块

6. **系统界面测试**（如实施）
   - [ ] 菜单功能正常
   - [ ] 设置选项正确
   - [ ] 画廊解锁正常
   - [ ] 语言切换功能正常

### 兼容性测试

- [ ] Steam 成就系统正常工作
- [ ] Steam 版原有功能不受影响
- [ ] 可以正常保存/读取进度
- [ ] 界面和系统功能正常
- [ ] 游戏运行稳定（无崩溃、无内存泄漏）

### 性能标准

- [ ] 补丁安装时间 < 10 分钟（视补丁大小）
- [ ] 游戏启动时间无明显增加
- [ ] H 场景加载无明显延迟
- [ ] 内存占用在合理范围
- [ ] 帧率稳定（无卡顿）

## 回归测试清单

每次修改后必须重新验证：

1. **基础验证**
   - [ ] 运行 `arcbuild.verify()` 检查所有 Arc 文件
   - [ ] 检查 SHA256SUMS
   - [ ] 验证脚本数量

2. **调用链验证**
   - [ ] 运行调用链分析工具
   - [ ] 检查所有跳转目标存在
   - [ ] 检查资源配对正确

3. **实机测试**
   - [ ] 测试关键场景（至少一条角色线的完整流程）
   - [ ] 测试 H 场景触发和续接
   - [ ] 测试文本显示和语音播放

4. **系统功能验证**
   - [ ] 验证 Steam 成就系统
   - [ ] 验证保存/读取功能
   - [ ] 确认无新增错误

## 质量门禁

每个阶段必须通过以下检查才能进入下一阶段：

1. **文档完整性**：相关文档已更新
2. **代码质量**：脚本支持幂等性和回读校验
3. **功能验证**：阶段目标功能验证通过
4. **无回归**：未引入新的问题
