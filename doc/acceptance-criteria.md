# 验收标准

> **粒度**：本文件是**总体验收标准**，只列**模块级的必要条件与判定口径**。
> 逐项机械断言在 `script/final_verification.py`（`python script/build_patch.py --check` 一次跑完）与 `script/audit/*`，判据的来路在对应专题文档 —— **细节不在此复制**（复制一份就会随之漂移）。

## 功能验收

### 还原与调用链

- [ ] 12 个就地插入宿主：与源 CCS 对位后**恰好一次、无缺失、无重复、无倒序**，且出口集合 == Steam 原档（`script/audit/audit_inline.py`）
- [ ] `CCB2017_EN` 选项分支 —— 全项目**唯一**的「增加跳转」例外：提示句 + `0f` 两条目 + 两张分支入口清框格 + 孤岛 18 行 ↔ 源 CCS 行 31..48 + 末条 `06` → `k=80`（`final_verification.py` 的 `check_ccb2017_branch()`；形状见 [call-chain.md](call-chain.md)「选项分支」）
- [ ] 所有文件内跳转（`06`、`0f` 条目、`01` 的 `a`/`b`）的落点都是**指令首字节**
- [ ] 跳转目标脚本存在（无悬空引用）；脚本数 == Steam 原档（363 个 `*_en.ws2`，无遗留还原脚本）
- [ ] 宿主「第一句对话之前」的场景开场件（`SCENETITLE*` / `SGCC*` / 鉴赏钩子）仍在
- [ ] **CG 解锁旗标位点守恒**：每个 `0b` 旗标的置位点数与 Steam 原档逐 id 相等（`audit_inline.py` 的「旗标位点守恒」闸）——只查"有无"会漏掉位点数回退（解锁时机推迟）；切除区内的解锁组由 `splice_restoration.py` 一律保留 `[0b ×N][04 CG_ACHIEVEMENT]` 并置于插入段前端（不含 `33` 显示——演出归还原段；规则见 [call-chain.md](call-chain.md)「解锁指令的保留」）
- [ ] ws2 末尾 8 字节 == `(0x14 条数, 0f 条目数)` —— `MessageFlag.dat` 位图容量的来源，写错会实机崩溃（见 [engine-mechanics.md](engine-mechanics.md)「MessageFlag.dat」）

### 资源

- [ ] 还原区间引用的 **CG / 背景 / 蒙版 / 立绘 / 语音**在归档里都能解析（缺失即卡死引擎）
- [ ] 补入的还原 CG 一律落在 `EVCC9XXX` 段，任何归档都不含 `CN_` 前缀（引擎只加载 `EVCC` 前缀，见 [pna-resources.md](pna-resources.md)）
- [ ] 语音为 OGG（`.soundlevel` 缺失可接受）

### 汉化

- [ ] 每个含文本的 ws2 都有配套 lng；无 lng 的 ws2 全部是无文本的系统 / 动画脚本（`0x14` 计数为 0）；`lng 条数 == 14 条数 + Σ(0f 的 count)`（`check_lng_pairing()`）
- [ ] 对话格必带尾部控制符（`%K`/`%P`/`%N`）、选项格必不带（`check_tails`）
- [ ] 名字框与「出处台词」的发话人一致：正文取自原版 ⇒ 名字框取该源行 `[話者]`；自译格 ⇒ 保持 Steam 的（判据与逐格机械核法见 [localization.md](localization.md)「语音与角色名」）
- [ ] 实机：正文 / backlog / 存读档 / 选项为思源黑体 Medium、人名框 Bold；无乱码，无需玩家预置系统字体
- [ ] 系统界面：`Script.arc` 的 14 个成员齐备（菜单 / 设置 / 画廊可用）；`SysGraphic.arc` 的替换图层逐字节兑现、未替换图层逐字节原样（`check_sysgraphic()`）

## 质量标准

- [ ] 全部 Arc 过 `arcbuild.verify()`（无 null padding）
- [ ] **流水线复跑 0 处改动** —— 各步幂等（先把 `asset/Rio.arc` 复位到流水线基线再复跑；报出改动即某步破坏了自己的输入）
- [ ] 归档读写字节稳定（`check_idempotency()`）
- [ ] `payload/` 由**当前** `asset/` 生成，`generate_payload.py` 的回读校验全 `[OK]` —— 成员内容与**成员顺序**都要对（`asset/` 一改必须重生成，见 [technical-solutions.md](technical-solutions.md)「打包与发布」）

## 体验验收（玩家视角）

判据是**玩过原版的人，能不能在这一版里重拾原版体验**；冲突时按项目总原则：**游戏体验 > 还原原版 > 其他**。

### E1 认得出（原版覆盖）

- [ ] 原版范围内（293 个脚本，**按 CCS 聚合**）**未承载行 = 0** —— 每一行原版文本都能在某一格读到；Steam 新增的 35 个后日谈 / 追加剧本不核（这是**必要条件、不是充分条件**）
- [ ] **差分必须「覆盖」回去，禁止「追加」** —— Steam 用摘要 / 替代文本占住原版格子的站点，必须先删替代文本再落原版（走 `scene_slices.json` 的替换通道或表内 `drop`），**不得**让玩家把同一件事读两遍
- [ ] **「未承载行 = 0」与「零双写」必须同时成立** —— 只查前者对差分是**结构性盲区**；差分候选只能机械枚举给置信度，**每一处都要人工读原文裁定**（`op:drop` 不得批量套用）
- [ ] **不以「有没有 CG」判定 H／血腥场景是否还原** —— 无 CG 的纯文本场景对 CG 锚点回查是盲区，须走未承载行的语义核查
- [ ] 允许的缺口只有两类：① 已登记的工作项（[restoration-targets.md](restoration-targets.md)）；② 已裁定改走选项分支的站点（`CCB2017`）

### E2 不卡眼睛（排版与演出）

- [ ] **控制标记三族逐格判、不按组批量删**（判据是「该组在原版对应位置是否存在」）：翻页族＝正文格尾 `%K%P`；纯清框族＝独立 `%P` + 正文；整屏清空族＝独立 `%P` + 连排 `%N`
- [ ] 不出现「堆字 / 整段不翻页」；还原插入的每一句独立成页（判据是**原版该句本就占一页**，与插入段长短无关）；空白拍与原版节奏一致
- [ ] `15` 结构照抄 Steam —— 不得有游离的 `15`、相邻的 `15` 不得被压掉（`verify_ws2_conventions.py` 的连跑 ⊆{1,2} 断言）
- [ ] `op:drop` 的站点只删「非原版的多余正文 / 多余空行」，不得删三族成员（`drop` 删整格，见 [file-formats.md](file-formats.md)「0x15」）
- [ ] 同屏不出现同一句两遍（先查该格是否 `src:"zhfill"` 复用邻格中文）

### E3 读得通（连贯性）

- [ ] **台词切分可接受（裁定）** —— 按英文句的语义划分点切分、「适当的语句零散化」可接受（上下文连贯、意境相同即可）；只有四种情形算缺陷：① 切分破坏词或专名；② 某片只剩标点或语气字；③ 上下文连贯或意境被破坏；④ 两半之间插进了别的台词 / 说话人 / 新译正文（判缺陷必须写明命中哪一条）
- [ ] 无悬空、无自相矛盾 —— 不得「插半句」（逗号断头、指代无所指）；新译与还原段不得互相打脸
- [ ] **译注可以出现（裁定 · 不得误杀）** —— 原版中文本地化自带的「（译注：…）」「※…」照搬进成品不算缺陷；仅当**本项目自撰**的说明混进台词框时才处理
- [ ] **选项 / 菜单译法不要求逐词一致（裁定）** —— 不同语境用不同中文是正常的；只有**同屏或同族两个不同英文动作撞成同一个中文**才算缺陷
- [ ] 格间源行号单调不减、无倒序、无整段错挂（`script/audit/audit_inline.py`）
- [ ] 范围排除：民汉文本**既有**的语病、错字不属本项；新增或本批改写的文本的错误计入

### E4 动线完整

- [ ] 分支与选项全部可达，选项支两侧文本成对、无悬空选项
- [ ] 还原段引用的 CG / 背景 / 蒙版 / 语音齐备，不卡死引擎
- [ ] 实机：至少一位测试者完整通关一条角色线（见「实机测试清单」）

### 判级（逐站点归零制）

**缺陷以「站点」为单位管理，不以比例管理** —— 一处逗号断头、一处名字框串人、一句没翻页，对玩家都是完整的一次出戏；第 30 处和第 1 处同样成立。

- E1 / E2 / E3 / E4 **全部 pass / fail**：每一处缺陷要么修掉，要么**逐条明确裁定**为下述两种之一，否则不得关闭
- 出路只有两种：① **已登记工作项**（写进 [restoration-targets.md](restoration-targets.md)，注明缺口范围与计划）；② **经裁定的原版既有 / 豁免**（写明判据，由项目负责人**逐条确认**，不接受「批量归类后整体放行」）
- **禁止**用覆盖率、平均分、「某桶 N/M 场可放行」这类**聚合指标**作为放行依据 —— 聚合数字只能用于安排工作量（统计器有已知漏报，「没测出来」不等于「没问题」）

## 落地门槛（写盘前）

1. **规则不能代替判断，只能提供置信度** —— 结构四条、哨兵、逐格内容比对都是**机械判据**，职能是圈定要判的位置；「产物 == 表」的内容比对是**同义反复**（只验了写盘器忠实，没验内容对不对）
2. **必须 293 场全量语义校对**，且对着**落地后的真实产物**读（落地前的结论一律作废）；未逐字通读的场次**不得放行**；本批改动区域逐格回读
3. **机械检查是独立的第二道** —— 两者**同向**才算数；任一不同向 ⇒ 退回**单独语义判断**，不用阈值 / 规则兜

**顺序**：落表 → 重跑管线（机械全绿） → 293 场全量语义校对 → 修订 → 才谈「可发布」。
差分形态识别（改写 / 整段删+新写 / 压缩概述）见 [restoration-targets.md](restoration-targets.md)。

## 回归测试清单

每次修改后必须重新执行（脚本都是项目根的执行入口）：

- [ ] `python script/build_patch.py --check` —— 四道闸：表自洽、表 ↔ 产物对账、行号对位、全量验收
- [ ] 流水线复跑 **0 处改动**（先复位 `asset/Rio.arc` 到流水线基线再跑 `build_patch.py`）
- [ ] `python script/audit/audit_inline.py`（合并播放序与出口一致性）、`python script/audit_choices.py`（池位连续性、条数等式、选项槽位形态）
- [ ] `python script/audit/audit_row_alignment.py` —— **行号对位闸**：`op=ccs` 区间块必须与 Steam 的台词流逐格对齐（名字框 vs 源行说话人成片不符即错位；已在流水线「写盘之后」，机理见 [localization.md](localization.md)「区间块的行号对齐」）
- [ ] 改过 `tool/ws2disasm.py` / `tool/wsc2ws2.py` 时：`python script/audit/verify_ws2_conventions.py` 与 `python script/audit/convert_wsc.py --outdir tmp/converted_ws2_new`（`parse failures` / `count mismatch` / `roundtrip bad` 须全为 0）
- [ ] `python script/generate_payload.py` —— 回读校验全 `[OK]`
